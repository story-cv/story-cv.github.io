# Replit brief: new About page for story.cv

Replace the current `/about-us` page with the files in this folder. Design preview: see the StoryCV About Page artifact.

## Files

| File | Where it goes | What it is |
|---|---|---|
| `about-us.html` | Replaces the current About page file | Full page. Keeps the site's header, footer, GTM, cookie banner and `style.css` exactly as they are now. |
| `about-us.css` | Site root, next to `style.css` | Styles for this page only. Every class starts with `.ab-`, so nothing else on the site changes. Loads after `style.css`. |
| `about-us.js` | Site root, next to `script.js` | Subtle motion only. The page is fully readable without it. |

No new images. It uses the existing `/kavya-photo.webp` (once only, the duplicate photo is gone).

## Please keep

1. **One H1:** "Most people have done more than their resume says." (50 characters). The small orange label above it is a `<p>`, and so is "We built StoryCV to get it out of them." under the illustration. The big headlines in later sections are styled `<p class="ab-display">` on purpose, with the small orange label above each one as the real H2. Please don't turn them into headings.
2. **The Key facts `<dl>` and the FAQ stay as plain HTML in the page source.** Don't move them into JavaScript. AI crawlers only read what's in the HTML.
3. **FAQ uses `<details>`.** Answers stay in the HTML even when collapsed, which is what we want.
4. **Pricing uses the shared `pricing-cards-container` component** and `/pricing-cards.js`, same as /pricing. Nothing new to build.
5. **JSON-LD in the `<head>`:** WebSite (unchanged), Organization (updated), Person (Kavya), AboutPage, FAQPage. If you change an FAQ question or answer on the page, change it in the FAQPage block too.

## Worth a look

- `pricing-cards-container` is filled by JavaScript, so crawlers see an empty box there. That's fine for now because the Key facts table carries the pricing in plain text. Server-rendering the cards would be better long term.
- `style.css` gives every `<main>` padding. `about-us.css` resets it for this page only.

## Motion (all of it)

- Hero lines rise in on load, and the orange underline under "more" draws itself once.
- Hero illustration: the resume card settles in, "Managed a team." gets highlighted, the three chat bubbles pop in one after another, then "We built StoryCV to get it out of them." appears with its underline. It's all HTML and CSS (no image file), so it stays sharp and crawlers ignore it (`aria-hidden`).
- Sections fade up as they scroll into view. Only content below the fold is hidden first.
- Manifesto paragraphs start light and ink in as you read down.
- The "400+" count ticks up once.
- Small hover lifts on cards, links and buttons. The FAQ plus turns into an ×.
- All of it switches off for users with "reduce motion" turned on.
