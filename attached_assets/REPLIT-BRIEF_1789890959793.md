# New landing page: `/chatgpt-for-resumes`

## What I want

A new landing page for people searching "ChatGPT for resumes." They've tried ChatGPT on their resume, got polished but empty bullets, and gave up. The page names that problem, shows why it happens (ChatGPT only sees what you paste in), and shows how StoryCV fixes it (it asks about your work first).

It follows the StoryBrand order: header → stakes → founder video → the ChatGPT timeline → before/after slider → testimonial → three-step plan → objections → pricing → CTA → FAQ → related articles.

Motion should be subtle. It supports the story, it isn't decoration.

## The four things that must survive

These aren't style preferences. They're bugs that already came up while building this, and the obvious way to build each piece brings them back. However you restructure the CSS, check these four:

1. **Timeline dots sit centred on the line.** The existing `.timeline-line` / `.timeline-marker` rules in `style.css` are 8px out of line: line centre at 10px, dot centre at 18px. So copying the homepage pattern reproduces it. (The homepage has the same bug, worth fixing there too.)

2. **The hero caret sits right after "Managed the support team."** If the typewriter animates the text's `width`, the span fills the box and the caret ends up at the far right edge. Reveal the text another way, e.g. `clip-path`, so it keeps its natural width.

3. **"Record and transcribe" / "Listening…" stay centred under the mic in step 1.** If the labels are centred with `translateX(-50%)` and the crossfade animates `transform: scale()` on the same element, the animation wipes out the translate and the label drifts right. Centre them without using `transform`.

4. **"You're not bad at prompting." can never get stuck invisible.** The homepage's word-by-word reveal uses `animation-timeline: view()`, which leaves words at `opacity: 0` if the timeline never resolves. On this page, trigger the reveal off the `.visible` class that `scroll-animation.js` already adds.
